WebTransport tunnel probe

Opens a real browser WebTransport session to a Eustress host, the way the browser Player will. One run shows whether Chrome's handshake fits through the path, whether the browser lets this page reach the host's address, and whether the certificate pin is accepted.

Before you run

Start the host first: open the Space in Studio, press Play, then F9, and copy the join link. For a remote host set EUSTRESS_HOST_LAN=1 before starting Studio.

For the Private Network Access result to mean anything, open this page from a public HTTPS address, such as a staging deploy of eustress.dev. Opened from a file or from localhost it tests everything else.

Open DevTools (F12) first. When a step fails, Chrome prints the underlying net:: error in the Console, and that line is the most useful thing to paste into a report.
