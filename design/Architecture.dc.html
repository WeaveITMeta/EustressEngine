Not the same as attributes
An Attribute is a value on the part. A Parameter is a value in a domain, which is what makes it addressable by something outside the scene. Keeping them separate is what lets one be free-form and the other be governed.
Direction is not symmetric
Inbound reads a Frame and narrows it to one value; outbound takes one value and fans it to many targets. Sharing a provider name (Postgres, Firebase) does not make them one code path — and pretending otherwise is the trap.
The gap is one struct
Both ends exist. What is missing is the binding that names a Connector field for a domain key and remembers its last read — plus the system that ticks it. That is the smallest change that makes the whole diagram live.
