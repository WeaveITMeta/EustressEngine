Parameter row states
A Parameter is domain-scoped and can be bound in two directions. The row reads the same as an Attribute row until it is bound; binding is what earns the extra chrome.

Local
Value lives on the instance. Editable, no chrome beyond the link affordance. This is the default, so a Parameter is useful before any Domain exists.
Sourced · inbound
A DataSource owns the value, so the field is read-only and carries its age. Editing is refused rather than silently overwritten on next poll.
Published · outbound
You still own the value; every change emits an ExportRecord to the domain's targets. Editable, with delivery state on the row.
Faulted
A binding that cannot reach its source says so on the row. A stale value must never masquerade as a live one.
A parameter can be sourced and published at once — that is a relay, and the row shows both glyphs. The dotted prefix (hvac.) appears only for keys outside the default domain, so the basic case stays uncluttered.
